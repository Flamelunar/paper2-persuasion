# Data

`raw/` contains immutable public snapshots downloaded for v4 planning.
`processed/` is reserved for normalized records created after implementation is
approved. `manifests/` is reserved for split and transformation manifests.

The primary CToMPersu data remains in the project-shared
`data/CToMPersu/mysplit/` directory and is referenced rather than duplicated.

Dataset roles and restrictions are documented in `../docs/data_assessment.md`.
Source commits, licenses, sizes, and content digests are in `manifest.json`.
